Editing on the site gets the on-site editor (`mountSiteEditor`, which `getContentBridge` mounts there in place of the prompt box): a panel docked on the right with the site reflowed beside it, Ask and Edit fields, the scope always shown, answers with a before and after that preview on the page until kept (Keep it, Try another, Undo), hovered blocks named on the page, and a launcher at the bottom left to minimize, hide the outlines and exit. On the site `bridge.environment` is now the session's. The prompt box's default words follow the redesign: Ask / Edit fields for Prompt / Form, Exit for Exit editing, and “Describe a change, like “make it warmer”” as the placeholder; it draws the Obelism mark as the design system does.
