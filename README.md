# Obelism numbers SDK

The SDK of [Obelism numbers](https://numbers.obelism.studio), the events
every Obelism product shares.

- [`@obelism/numbers-sdk`](packages/sdk): page views, events and clicks on
  tagged elements, as a module or one script tag.

## Development

```bash
npm install
npm run build
npm run test:ci
npm run lint
npm run changeset   # before a release
```
